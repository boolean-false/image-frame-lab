Лабораторная работа 1. Вариант 16

Приложение на Flask добавляет рамку к изображению PNG или JPG.
Можно выбрать ширину и цвет рамки. Ниже выводится результат
и график распределения цветов исходного изображения.
Готовое изображение можно скачать в PNG.

Для запуска нужен Python 3.12

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py

После запуска открыть http://127.0.0.1:8036/

Проверка программы:
python -m unittest discover -s tests -v

В папке examples есть изображения для проверки
