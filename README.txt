Лабораторная работа 1. Вариант 16

Приложение на Flask добавляет рамку к изображению PNG или JPG.
Можно выбрать ширину и цвет рамки. Ниже выводится результат
и график распределения цветов исходного изображения.
Готовое изображение можно скачать в PNG.

Для запуска нужен Python 3.12

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py

После запуска открыть http://127.0.0.1:8036/

Проверка программы:
python -m unittest discover -s tests -v

В папке examples есть изображения для проверки

Перед обработкой нужно решить пример на сложение или вычитание.
Ответ проверяется на сервере. Капча действует 5 минут и используется один раз.

Страница /verify нужна для проверки работы преподавателем.
На ней указаны персональный токен и дата UTC.
Заголовок X-Verify-Hash содержит SHA-256 нормализованного HTML.

Сайт: https://image-frame-lab.onrender.com/
На бесплатном тарифе первое открытие после простоя может быть долгим.
Сессии и результаты временные: после перезапуска нужно обновить страницу.
